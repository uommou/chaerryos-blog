### 문제
###### 문제 설명

배열 arr가 주어집니다. 배열 arr의 각 원소는 숫자 0부터 9까지로 이루어져 있습니다. 이때, 배열 arr에서 연속적으로 나타나는 숫자는 하나만 남기고 전부 제거하려고 합니다. 단, 제거된 후 남은 수들을 반환할 때는 배열 arr의 원소들의 순서를 유지해야 합니다. 예를 들면,

- arr = [1, 1, 3, 3, 0, 1, 1] 이면 [1, 3, 0, 1] 을 return 합니다.
- arr = [4, 4, 4, 3, 3] 이면 [4, 3] 을 return 합니다.

배열 arr에서 연속적으로 나타나는 숫자는 제거하고 남은 수들을 return 하는 solution 함수를 완성해 주세요.

##### 제한사항

- 배열 arr의 크기 : 1,000,000 이하의 자연수
- 배열 arr의 원소의 크기 : 0보다 크거나 같고 9보다 작거나 같은 정수

---

##### 입출력 예

|arr|answer|
|---|---|
|[1,1,3,3,0,1,1]|[1,3,0,1]|
|[4,4,4,3,3]|[4,3]|

##### 입출력 예 설명

입출력 예 #1,2  
문제의 예시와 같습니다.

### 풀이
#### 처음 제출한 풀이
정확성은 통과헀지만 효율성에서 0점을 받았다.
```cpp
#include <vector>
#include <iostream>
#include <stack>

using namespace std;

vector<int> solution(vector<int> arr) 
{
    vector<int> answer;

    // 새로운 수가 나올 때마다 스택에 담아주고, 다음 수가 top과 동일하다면 패스한다.
    stack<int> st;
    for (auto n : arr) {
        if (!st.empty()) {
            if (st.top() == n) {
                continue;
            }
            else {
                st.push(n);
            }
        }
        else {
            st.push(n);
        }
    }
    
    while (!st.empty()) {
        answer.insert(answer.begin(), st.top()); // 벡터의 앞에 스택의 top 원소를 넣어준다.
        st.pop();
    }
    return answer;
}
```

#### 정답 풀이
```cpp
#include <vector>
#include <iostream>

using namespace std;

vector<int> solution(vector<int> arr) 
{
    vector<int> answer;

    for (int n : arr) {
        if (!answer.empty() && answer.back() == n) {
            continue;
        }
        answer.push_back(n);
    }
    return answer;
}
```

다른 사람들의 풀이를 검토해봤을 때 `unique()`함수를 사용하는 것이 가장 깔끔하고 간단한 방법이었다.
```cpp
#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;

vector<int> solution(vector<int> arr) 
{

    arr.erase(unique(arr.begin(), arr.end()),arr.end());

    vector<int> answer = arr;
    return answer;
}
```
